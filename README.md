# SpendWise – Student Expense Tracker

A modern and responsive Student Expense Tracker website designed to help students manage daily expenses, monitor monthly budgets, and develop better money-management habits.

## 📌 Project Overview

SpendWise provides a simple dashboard where students can record their expenses, categorize spending, track their budget, and review their transaction history.

## ✨ Features

- **Dashboard:** View monthly spending, total budget, remaining balance, and transaction count.
- **Add Expenses:** Record expense names, amounts, categories, and dates.
- **Budget Management:** Set and update your monthly spending limit.
- **Spending Charts:** Visualize expenses over the last seven days or six months.
- **Category Analysis:** View spending across food, transport, education, shopping, entertainment, and other expenses.
- **Transaction History:** View, search, filter, and delete recorded expenses.
- **CSV Export:** Export expense records for use in spreadsheet applications.
- **Responsive Design:** Use the website on desktop and mobile screens.
- **Local Storage:** Save expense records in the browser for later visits.

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive layout
- JavaScript – Application logic and interactive features
- Browser Local Storage – Saving expense data locally

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `StudentExpenseTracker.html` in a web browser.
4. Alternatively, use the Live Server extension in VS Code.
5. Add expenses and set your monthly budget to get started.

## ⚠️ Current Limitations

This version is a frontend application. Expense data is stored in the browser's local storage and is not synchronized between devices or users. A backend and database are required for shared, account-based storage.

## 🎯 Project Objective

To develop a user-friendly expense management website that helps students understand their spending patterns, plan monthly budgets, and improve financial awareness.
